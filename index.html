Kostenlos auf GitHub hosten

Diese komplette Website besteht aus einer einzigen index.html Datei und nutzt WebRTC (PeerJS), sodass du keinen eigenen Backend-Server benötigst:

Schritt 1: Erstelle auf github.com ein neues öffentliches Repository (z. B. rummikub).

Schritt 2: Lade diese Datei unter dem Namen index.html in das Repository hoch (Add file → Upload files → Commit).

Schritt 3: Gehe im Repository auf Settings → Pages, wähle unter Branch main aus und klicke auf Save.

Nach ca. 60 Sekunden ist euer Spiel unter https://deinname.github.io/rummikub/ auf jedem Smartphone & Computer erreichbar!

Spielregeln & Smartphone-Steuerung

Kinderleichte Bedienung (Handy & PC)

Tippe einfach einen oder mehrere Steine auf deinem Brettchen (oder auf dem Tisch) an, um sie auszuwählen. Tippe danach auf „+ Neue Gruppe / Straße“ oder auf eine bestehende Reihe auf dem Tisch, um die Steine dorthin zu legen!

Gültige Kombinationen (mind. 3 Steine)

  • Gruppe: 3 oder 4 Steine mit derselben Zahl, aber in unterschiedlichen Farben (z.B. 7 7 7).
  • Straße: Mindestens 3 aufeinanderfolgende Zahlen in derselben Farbe (z.B. 4 - 5 - 6 - 7).

30-Punkte-Erstmeldung

Beim allerersten Auslegen musst du mit eigenen Steinen mindestens 30 Punkte erreichen (Zahlenwerte addiert). Erst danach darfst du auch bereits ausliegende Gruppen auf dem Tisch umbauen!
